# 巴蘭騎驢 3D(balaam-donkey3d)

> HFPC 聖經遊戲系列 · 民數記 22:21-33。**fork 自 donkey-jerusalem3d 騎乘引擎**(2026-07-16)。
> ★你扮演的是那頭**驢**——全場**唯一看得見「耶和華的使者站在路上、手裡有拔出來的刀」**的角色。
> 巴蘭(騎在你背上的先知)看不見;你每次避讓慢了,就挨他的杖(演出溫柔化,不血腥)。

「驢看見我就三次從我面前偏過去；驢若沒有偏過去，我早把你殺了，留牠存活。」(民22:33,和合本,已 cuv 查驗)

## 玩法

- **巴蘭之路**:馱著巴蘭走完曠野之路。沿途一站站「天使站」擋在路中——
  在**綠區**按「避讓」=驢及時避開(三幕演出照經文順序:①轉入田間 ②貼牆擠過 ③極窄之處臥下);
  錯過時機=「驢遲疑,巴蘭的杖落下」+4 罰分(巴蘭揮杖+驢委屈搖頭+小踉蹌)。
  超時每 4 秒 +1 罰分;**永不會輸**——再多罰分也走得完。
  **零罰分=「驢兒忠心!牠救了主人的命」**(天降彩花+曉臻唸民22:33);有罰分=民22:28(驢開口)。
- **終局演出**(民22:31):走到終點,耶和華使巴蘭的眼目明亮——大天使現形全場、巴蘭俯伏下拜,然後才結算。
- **練習小路**:無限圈數自由練節奏與避讓。

驢會沿曠野土路自己走——按住「快步」(W/↑)拿捏節奏,天使靠近時在綠區按「避讓」(空白鍵/點畫面)。
判定=畫面:按下當下定結果,巴蘭的杖在判定後才揮下。

- **三幕場景**:田間寬路(綠斑莊稼)→ 葡萄園窄路(兩側矮石牆+葡萄藤)→ 極窄山道(兩側石壁)。
- **驢毛色三檔**:灰褐/深灰/淺棕(首頁選單即時換色)。
- 五難度(幼兒不限時+強輔助 → 職業 11 站窄綠區)。

## 開發

```bash
npm install
npm run dev                      # 本機試玩(dev 不註冊 SW)
npm run build                    # 產物在 dist/
node scripts/gen-voice.mjs       # 烤人聲(雲哲 12 句+曉臻 3 節;產物進 git,離線可玩)
node scripts/verify-balaam.mjs <url> <outDir>  # Playwright 端到端(完美避讓/全挨打/換色)
```

引擎重點(承 donkey-jerusalem3d ← equestrian3d):CatmullRom 閉環賽道(`posAt/tangentAt` 里程域)、
skijump 同款綠區判定式 `quality = 1 - err/(window*2.2)`、四足 makeDonkey(矩形身體+雙節腿+有臉+大長耳)、
巴蘭=系列 makePerson 先知裝+木杖(引擎控 NPC)、天使=makePerson 白袍+光暈+雙翼+發亮的刀。
人聲鐵律:預烤 mp3,缺檔只出字幕。
